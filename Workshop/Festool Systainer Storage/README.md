# Festool Systainer Storage

## Scope of delivery

- Stable multiplex (plywood) body with 5 Systainer telescopic drawer positions
- 4 ball bearing-mounted swivel castors (2 with locking brakes)
- **Note:** Supplied without Festool rails — these can be added on quote.

## Product description

**Organisation on wheels.**

Order on wheels. This mobile storage system for Systainer and SORTAINER helps you work efficiently. The Systainer-Port provides order and mobility in the workshop: all the necessary tools and equipment can be rolled over to the workplace quickly and easily. The height of the individual pull-out drawer positions can be adjusted — for flexible equipping with different Systainer and SORTAINER sizes.

- Locking brake for extra stability
- Storage system for Systainer and SORTAINER
- Mobile thanks to swivel castors with ball bearings

## Ideally suited for

Quick and easy access to parts at the workplace, assisted by clear labelling.

- **Construction:** Multiplex (plywood) body
- **Accessory/Part type:** Frame
- **Product Range:** Festool Systainer compatible
