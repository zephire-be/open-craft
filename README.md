# open-craft

Open-source maker designs by Zephire — woodworking, laser engraving, 3D printing & metal casting.

## Repository structure

The repository is organised by category. Each category directory groups together the related projects.

- **`Workshop/`** — All projects related to workshop furnishing and organisation (storage racks, tool holders, jigs, layout designs, etc.).

Each project lives in its own subdirectory and follows a consistent layout:

```
<Category>/
└── <Project name>/
    ├── README.md   # Project description, scope, materials, notes
    ├── media/      # Images, photos, renders
    └── src/        # Source files (CAD, vector, slicer, etc.)
```

### Example

```
Workshop/
└── Festool Systainer Storage/
    ├── README.md
    ├── media/
    └── src/
```
